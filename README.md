# Slot Academy — スロット学習サイト
初心者向けの教科書と操作デモを統合し、将来的に複数機種の教材を追加するプロジェクトです。

## まず使えるもの
- `index.html`: 初期版の **動作確認済みSAO2学習デモ**への入口。抽選やゲーム数は学習用の仮値で実機再現ではありません。
- `docs/sao2-textbook-legacy.html`: 初期の教科書HTML（ブラウザーで閲覧）。
- `docs/sao2-textbook.md`: 図解統合版の教科書原稿（最新の原稿）。
- `docs/sao2-visual-guide.html`: 図解資料のHTML。
- `draft/index.html`: **未完成**の複数機種UI・動的フロー画面の草案。依存ファイルが未作成なので現時点では動作しません。
- `demo/index.html`: 変更前の旧デモ原本。
- `docs/ASSET_STATUS.md`: PDFなどバイナリ資料の移管状況。

## 今回のPRの目的
作業途中の成果をなくさずGitHubに記録し、Codexへ次の実装を引き渡します。このPRは完成版と混同しないでください。レビュー/マージと実運用の動作確認は別です。

## 公開方法
`.github/workflows/pages.yml` はGitHub PagesをGitHub Actionsから公開する設定です。PagesのSourceが「GitHub Actions」になっていて、PRがmainへマージされた際にActionsが正常終了する必要があります。現時点では **公開完了を確認していません**。

## 基本方針
- まず共通基礎（用語・BET・レア役・CZ・AT・引き戻し）、次に機種別教科書。
- プレイヤーの操作に合わせて現在地が変わるフロー図を用意する。
- 機種ごとにスペック・画像の出典・専用フロー・シミュレーター設定を切り替える。
- 著作権未確認の実機画像は無断転載しない。
- 学習用の確率/払出を実機の解析値や期待値と混同しない。
