# Slot Academy

スロットを基礎から学び、操作デモと現在地フローで理解する非公式の静的Web教材。Androidスマートフォン優先、PC対応。外部API・認証・バックエンド・決済はありません。

## 起動・検証

Node.js 24とPython 3を使用します。アプリの配信自体にはnpmパッケージは不要です。

```sh
npm ci
npm test
npm run serve
# 別シェルで（初回のみブラウザーを導入）
npx playwright install chromium
npm run test:browser
# 既存Chromiumを使う場合
CHROMIUM_PATH=/usr/bin/chromium npm run test:browser
```

`index.html` が現在の入口。基礎10章→応用9章→SAO2題材9章を順に読み、デモ、機種ライブラリー、辞典、28問の復習へ移動します。印刷メニューはWeb教材全章を印刷/PDF保存するもので、未移管の原本PDFとは別です。

## 実装と教材の境界

- `app/engine.js`: DOMから独立した1G操作・投入/払出・リプレイ・状態遷移。レバーで役を確定し、停止操作で入賞判定。二重BET・停止の重複を防止。
- `app/machines.js`: 機種ごとの状態・分岐・教材確率。状態遷移は `app/machine-rules.js`、実機情報・出典の正本は `app/sao2.js` に分離。追加機種には固有状態遷移のハンドラーも必要です。データ追加だけで任意の実機を完全再現する設計ではありません。
- SAO2題材: 通常、CZ、AT、ラストアタック、上位CZ、上位AT、終了後の引き戻し練習。短縮G数と仮抽選です。実機のリール配列・滑り・押し順ナビ・差枚数管理・役別抽選・前兆延長・上位特化ゾーンは未再現。
- 架空リールラボ: 実在しない比較用機種。通常→ボーナス、スイカ目押しで6枚／外すと0枚。選択で表示と進行ロジックが切り替わります。
- フロー図はデモと同一状態を参照し、現在地・消化/残G・分岐・移動理由・関連教材を表示。スマホには固定の現在地表示も設置。
- 任意の役・結果・状態を選ぶ操作は教材専用。リセット・機種切替は全状態を初期化。練習移動は未完了のBETを返却。

## 配信とCI

`node scripts/build.mjs` で公開対象だけを `_site/` にコピーします。`.git`、テスト、npm依存を配信しません。PRの `check.yml` は単体・状態遷移・教材整合性と、`/slot-academy/` 配下でのブラウザーテストを実行します。PagesのSourceはGitHub Actionsを選択します。

`pages.yml` はmainへのpushまたは手動操作で検証後に配信します。PRブランチへのpushだけでは公開しません。マージ・公開はユーザー承認後に行います。Actions成功と本番URLの操作確認は別で、未実施を成功とは記録しません。戻す際はPRコミットをrevertして通常のレビュー・配信を行います。
