# Slot Academy 横断品質レビュー — 2026-10-26

対象：GitHub `miiifa/slot-academy` main `4b50d0e` のコード、および再設計モック `flow-prototype-with-demo.html`。ブラウザーの表示・実人間の理解度テストは**このレビューでは未実施**。コードを読んで確認できた挙動と、UX上の仮説を分ける。

## 総評

ユーザーの指摘した「リール」「教科書」「デモの細かさ」は3つの個別バグとしてだけ扱うべきではない。より根本には **画面がユーザーの学習段階ではなく実装機能ごとに構成されている**、**機能テストと教育効果のテストが混同されている** という問題がある。改善目標は正確性・情報量そのものではなく「今何が起き、なぜ、次に何をすべきか」を初心者が理解できること。

## 修正時に横断して確認する観点

今後は、ユーザーの指摘を修正する際、必ず同じ機能群の以下も調べる：

1. **最初の5分**：初見で迷う操作、説明過多、目的が見えない場面、例外分岐。
2. **全状態の一周**：通常→CZ成功/失敗→AT→終了→引き戻し成功/失敗→通常。
3. **境界・中断**：残高不足、BET途中、リプレイ、状態遷移直後、リセット中、モード切替、ブラウザー戻る。
4. **教材とUIの整合**：章の言葉、内部モデル、フロー図、結果表示、機種別スペックが矛盾しないか。
5. **端末と学習効果**：390pxと360px、コントラスト・文字量・タップ領域、初心者が説明なしで課題を達成できるか。
6. **回帰**：修正項目ごとに再現手順とテストを残し、mainへ入れる前後で比較。
